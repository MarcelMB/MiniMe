# minime-core

Rust core of the browser MiniMe (design: `docs/browser-app.md`). One crate, two builds:

- **native** check harness: `cargo build --release`, then
  `target/release/minime-core --raw RAW --inputs INPUTS --out OUT [--check-frames T.npy]`;
- **wasm** for the web worker: `npm --prefix web run wasm` (writes `web/src/stream/pkg/`).

**Inputs:** raw GREY AVIs + `INPUTS/` from `experiments/streaming/ref_dump.py`
(`params.json`, footprints `A_*.npy`, `shifts.npy`, `ymean.npy`, `sn.npy`).
**Outputs:** the `.npy` files of `ref_dump.py`'s `ref/` (traces `C`, `f`, the sums
`stats_*`, footprints `Asp_*` / `Amerged_*`, ...) + `summary.json`; check with
`experiments/streaming/check_rust.py REF_DIR OUT`.

| Module | Python reference |
|---|---|
| `avi` | `io.read_avi` (GREY AVI, `idx1` or chunk scan) |
| `preprocess` | `cv2.medianBlur`, `cv2.warpAffine` (OpenCV 5 NEON: fused lerp), tophat; the scalar versions (`median_blur_huang`, `shift_scalar`, `tophat_scalar`, ...) are the references of the fast ones |
| `median`, `median_net`, `morph`, `warp`, `simd`, `fsimd` | the fast per-frame kernels: sorting-network 7 x 7 median (`median_net.rs` is generated by `tools/gen_median_net.py`), doubling-window tophat, and the sub-pixel shift / float Gaussian / 2x resize with an exact f64-pair emulation of `fma`; 16 x u8 lanes on wasm `simd128`, NEON, SSE2 (plain arrays elsewhere); bit-identical to the scalar code (tests in `preprocess`, `filters`, `tests/real_frames.rs`) |
| `stream` | `stream.TraceModel`, `Support`, `stream_pass`, `spatial_from_stats`, `merge_from_stats` |
| `nnqp` | `spatial_kernel.solve_nnqp` |
| `butter` | `scipy.signal.butter(..., output="sos")` + `sosfilt` |
| `linalg` | `init._solve_normal` (Cholesky / pinv) |

`cargo test` runs the unit tests (`tests/real_frames.rs` compares the fast kernels with the scalar ones on
225 real frames when `~/minian_testing_local/synth_v4_5min/raw` or `$MINIME_RAW` exists);
`cargo run --release --example bench_prep [RAW_DIR]` times every kernel, scalar against fast, in one process;
`--example profile_frame` times one pass-1 frame stage by stage; `tools/wasm-bench/run.sh RAW WORK PORT`
does the kernel A/B in headless Chrome (wasm built with the `bench` feature).
